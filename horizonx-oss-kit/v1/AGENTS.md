# AGENTS.md — HorizonX OSS Kit

## Goal
Reusable cinematic web primitives for premium sites.

## Hard rules
- Do not copy proprietary HorizonX source, shaders, assets or copy.
- Rebuild techniques from first principles with open-source libraries.
- Motion + Lenis first; Three/R3F only when 3D materially improves the result.
- Mobile-first; do not hijack browser scrolling.
- Respect `prefers-reduced-motion`.
- Do not invent client claims, logos, awards, prices, metrics or testimonials.
- Use project-owned assets when integrating into a real site.
- Before merging: typecheck, build, iPhone-size test, desktop test, reduced-motion test.
