# OpenCode / Codex prompts

## Reference effect without proprietary copying
Analyze the supplied screenshot/video and separate layout, typography, lighting,
timing, scroll behavior, and DOM-vs-WebGL responsibilities.

Rebuild the effect from first principles using Motion, Lenis and, only when useful,
Three.js/R3F. Do not scrape, de-minify, copy or reproduce proprietary code,
shaders, images or copy. Work in a branch, run typecheck/build and provide a preview.
Do not merge without approval.

## Premium hotel landing
Create a mobile-first hotel landing using only supplied real hotel photos.
Direction: ivory, coffee, champagne and bronze; editorial typography; restrained
parallax; one signature WebGL/canvas moment maximum. Do not invent amenities,
awards, prices or testimonials.

## Scroll sequence
Implement a sticky canvas sequence with progressive preloading, nearest-frame
rendering, resize safety, a lighter mobile path and reduced-motion fallback.
Never hijack scrolling.
