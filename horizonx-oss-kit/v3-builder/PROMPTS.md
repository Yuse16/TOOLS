# Prompts base

El builder genera un prompt dinámico, pero estas plantillas sirven como respaldo.

## Integrar un efecto

Integra únicamente el efecto seleccionado del HorizonX OSS Kit V3.

Reglas:
- no reescribas toda la app;
- conserva rutas, auth, forms, datos y business logic;
- mobile-first;
- reduced-motion;
- no inventar assets ni claims;
- una rama nueva;
- typecheck + build;
- preview antes de merge.

## Convertir demo procedural a contenido real

Conserva la interacción y estructura del efecto, pero reemplaza el contenido procedural por
assets suministrados por el proyecto. Usa responsive images, formatos modernos y lazy loading.
No cambies lógica de negocio.
