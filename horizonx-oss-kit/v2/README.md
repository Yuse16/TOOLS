# HorizonX OSS Kit V2 — Catálogo Visual

Laboratorio navegable con 8 efectos reutilizables: Liquid Hero, Scroll Sequence,
Particle Field, Glass Orb, Image Distortion, 3D Product, Pinned Storytelling y Page Transitions.

No contiene ni copia código propietario de HorizonX. Son recreaciones desde principios generales
con librerías open source.

## Ejecutar
```bash
npm install
npm run dev
```

## Gate
```bash
npm run typecheck
npm run build
```

## Uso recomendado
Abre `/`, entra a un lab, valida el efecto y copia únicamente el componente/estilos necesarios
a tu proyecto real. No lleves todo el kit a una app existente.
