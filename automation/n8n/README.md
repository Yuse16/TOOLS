# n8n

Repo de referencia: https://github.com/n8n-io/n8n

## Rol en nuestro ecosistema

Motor de automatización detrás de sitios y sistemas.

Ejemplos:
- formulario web → CRM → WhatsApp/correo;
- nuevo lead → clasificación → seguimiento;
- reportes periódicos;
- sincronización entre APIs;
- automatizaciones con IA.

## Regla arquitectónica

No meter n8n dentro de AureStay ni de un frontend. Usarlo como servicio/orquestador separado cuando aporte valor.

## Nota

Revisar licencia, versión y requisitos de despliegue antes de cualquier uso comercial.
