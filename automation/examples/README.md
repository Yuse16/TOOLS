# Automation Examples

Espacio para guardar workflows propios y documentados.

Formato recomendado por ejemplo:

```text
examples/
└── lead-intake/
    ├── README.md
    ├── workflow.json
    └── sample-payload.json
```

Nunca guardar:
- API keys;
- tokens;
- contraseñas;
- datos personales reales de clientes.
