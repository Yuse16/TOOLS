## OrbitX OSS

- `orbitX-oss/v1/` — starter cinematográfico base.
- `orbitX-oss/v2/` — catálogo visual con laboratorios por efecto.
- `orbitX-oss/v3-builder/` — builder visual con perfiles, selección de efectos, snippets, dependencias y prompts para OpenCode/Codex.

OrbitX OSS es nuestro nombre interno para el kit. Los componentes recrean técnicas generales desde cero con librerías open source y no contienen código, assets o shaders propietarios de HorizonX.

## Repos de terceros

Los directorios de browser automation, web intelligence, automation, AI platforms y research contienen **fichas de referencia**, no copias completas de los repos externos. Así evitamos forks desactualizados, respetamos licencias y conservamos claro qué queremos reutilizar o estudiar.

## Objetivo

Guardar aquí componentes, kits, integraciones, research y herramientas que podamos reutilizar en AureStay, Orbit Code, webs de clientes, automatizaciones y futuros proyectos.
