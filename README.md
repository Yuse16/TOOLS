# TOOLS

Repositorio central de herramientas reutilizables para futuros proyectos.

## Kits disponibles

- `horizonx-oss-kit/v1/` — starter cinematográfico base.
- `horizonx-oss-kit/v2/` — catálogo visual con laboratorios por efecto.
- `horizonx-oss-kit/v3-builder/` — builder visual con perfiles, selección de efectos, snippets, dependencias y prompts para OpenCode/Codex.

## Objetivo

Guardar aquí componentes, kits, utilidades, integraciones y herramientas que podamos reutilizar en proyectos como AureStay, Orbit Code, sitios de clientes y automatizaciones.

> Los kits HorizonX OSS recrean técnicas visuales generales desde cero con librerías open source. No contienen código, assets o shaders propietarios de HorizonX.
