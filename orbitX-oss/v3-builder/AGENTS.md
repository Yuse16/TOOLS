# AGENTS.md — HorizonX OSS Kit V3

## Purpose
Visual builder + isolated labs for reusable cinematic web patterns.

## Hard rules
- Do not copy proprietary HorizonX implementation, shaders, assets, text or downloadable code.
- Rebuild techniques from first principles.
- Prefer DOM/CSS/Motion first.
- Use Canvas/WebGL only when it materially improves the experience.
- Mobile-first.
- Respect `prefers-reduced-motion`.
- Never hijack browser scrolling.
- Cap WebGL DPR at 1–1.5.
- Do not invent client data, awards, prices, metrics, logos or testimonials.
- Integrate effects in a branch and do not merge without preview approval.
