# Dify

Repo de referencia: https://github.com/langgenius/dify

## Para qué nos puede servir

Plataforma para experimentar con:
- asistentes internos;
- RAG;
- workflows de IA;
- agentes;
- APIs de aplicaciones LLM.

## Dónde sí

Prototipos rápidos, herramientas internas y experimentación.

## Dónde no por defecto

No sustituir arquitecturas ya definidas como AureStay sólo por tener una plataforma visual.

## Gate

Evaluar:
- licencia;
- self-hosting;
- privacidad;
- costos de modelos;
- portabilidad de workflows.
